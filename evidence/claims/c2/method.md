# C2 four-route method

1. Compare the exact paper language with the conditions in its primary cited
   precursor.
2. Check an exact rational counterexample to Proposition 3:
   `f_n=max(0,x-(1-1/n)) -> 0` uniformly while the boundary gradient error
   remains one.
3. Constructively verify the corrected smooth/interior special case with
   max-tangent approximants to `x^2/2`.
4. Attempt theorem-level falsification, and independently reject the tempting
   boundary-spike candidate because the target zero function itself has an
   exact finite-support approximant.

Each route has a different source interpretation and analytical mechanism.
The fourth route is included because confidence remained LOW after the first
three.
