Global assumptions relevant to C1–C3:

- The v1 paper defines `X` and `Y` as subsets of Euclidean spaces.
- The density proof invokes compactness/total boundedness of `Y` and uniform Lipschitz control of `Φ`.
- C1 quantifies over every `ε > 0` and every `Y`-convex `f`.
- C2 assumes semiconvexity of `Φ` and claims density in a uniform gradient topology "where the gradients exist."
- C3 fixes a finite support set `Y~`; a parameter vector is lean when every branch is active at some `x ∈ X`. Theorem 3 assumes the `X`-transform supremum is attained (for example, compact `X`).
- C4–C5 use one buyer, independent `Uniform([0,1]^n)` values, linear surplus, zero production cost, and dimensions `n ∈ {1,2,5,10,20}`.
- C6 requires Kantorovich dual feasibility; map recovery additionally requires `y ↦ ∇_x Φ(x,y)` to be a diffeomorphism (the v1 text also calls this the twist condition).
